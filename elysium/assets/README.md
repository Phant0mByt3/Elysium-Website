# /assets

Reserved for downloadable or binary files that aren't images -- most
notably ambient background music and UI sound effects for the audio
system already wired up in index.html / js/main.js.

Suggested layout:

    assets/audio/ambient-theme.mp3
    assets/audio/ui-click.mp3

Once a licensed track is added, uncomment the matching <source> tag
inside the #ambient-audio and #click-audio elements in index.html.
